# FASHION STORE

Навчальний вебзастосунок інтернет-магазину одягу та взуття, створений у межах курсової роботи з дисципліни «Технології створення веб застосунків».

## Технології

- Python 3, Django 5.2
- PostgreSQL
- HTML5, CSS3, Django Template Language
- Git та Visual Studio Code

## Основні можливості

- Головна сторінка та каталог товарів
- Пошук товарів за назвою, описом, брендом і категорією
- Фільтрація за категорією, сортування та пагінація
- Перегляд сторінки товару й відсотка знижки
- Реєстрація, вхід і вихід користувачів
- Адміністрування категорій, брендів, товарів, варіантів та складських залишків
- Адаптивне оформлення сторінок

**Обмеження:** оформлення замовлень, онлайн-оплата, повноцінні кошик і обране не реалізовані у поточній версії.

## Локальний запуск

1. Клонуйте проєкт:

   ```powershell
   git clone https://github.com/Gaben6769/fashion-store.git
   cd fashion-store
   ```

2. Створіть і активуйте середовище:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Створіть `.env` у корені проєкту та вкажіть **свої** значення (не завантажуйте цей файл у Git):

   ```env
   DJANGO_SECRET_KEY=replace-with-a-long-random-secret
   DJANGO_DEBUG=True
   DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost
   DB_NAME=fashion_store
   DB_USER=your_postgres_user
   DB_PASSWORD=your_postgres_password
   DB_HOST=127.0.0.1
   DB_PORT=5432
   ```

4. Створіть зазначену базу та користувача PostgreSQL із необхідними правами. Потім застосуйте міграції:

   ```powershell
   python manage.py migrate
   python manage.py check
   python manage.py runserver
   ```

5. Відкрийте в браузері `http://127.0.0.1:8000/`. Адміністративна панель доступна за `/admin/` після створення суперкористувача командою `python manage.py createsuperuser`.

## Автоматизовані тести

```powershell
python manage.py test -v 2
```

У ході курсової роботи локально виконано **16 тестів**, результат **OK**, без помилок (14 листопада 2026 року; тривалість 0,993 с). Тести охоплюють каталог, властивості знижки, складські залишки, сторінки та реєстрацію користувача. Підсумки окремого запуску не гарантують такого самого результату в кожному середовищі.

## Структура репозиторію

- `config/` — налаштування Django та загальна маршрутизація
- `accounts/` — реєстрація й автентифікація
- `catalog/` — категорії, бренди, товари, варіанти, пошук та сторінки каталогу
- `inventory/` — моделі складських залишків
- `storefront/` — головна сторінка
- `templates/` — HTML-шаблони
- `static/` — CSS та інші статичні файли
- `media/` — демонстраційні медіафайли

Не публікуйте `.env`, паролі, секретні ключі та реальні персональні дані.
